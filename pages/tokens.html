Biblioteca Central de Design Tokens

Design Tokens são as decisões atômicas de estilo do Banco Central do Brasil. Utilize sempre as variáveis CSS (ex: var(--bcb-brand-blue)) para garantir coerência visual, suporte a tema escuro e conformidade com os padrões de acessibilidade do Governo Federal e do BCB.

Tipografia e Escala Fluida

O Banco Central do Brasil adota a fonte Ubuntu para interfaces digitais e Cormorant Garamond para composições editoriais refinadas. A escala tipográfica é construída com funções CSS clamp() para fluidez responsiva automática.

Famílias de Fontes Registradas

Ubuntu
--bcb-font-ubuntu: 'Ubuntu', 'Segoe UI', Arial, sans-serif;

Texto de exemplo: Transparência e estabilidade para o sistema financeiro nacional.

Cormorant Garamond
--bcb-font-cormorant: 'Cormorant Garamond', serif;

Texto editorial: Relatório de Estabilidade Financeira e Políticas Monetárias.

Tokens para Modo Alto Contraste

Conjunto de tokens dedicados para usuários que ativam recursos de acessibilidade para baixa visão e contraste máximo, seguindo as diretrizes do Modelo de Acessibilidade em Governo Eletrônico (e-MAG).

Simulação de Superfície em Alto Contraste

Superfície Nível 2 (--bcb-hc-bg-level-2: #222222)

O texto de leitura principal utiliza contraste puro (--bcb-hc-text: #FFFFFF) com fundo escuro profundo.

Hiperlinks são destacados em amarelo puro (--bcb-hc-link: #FFFF00)

Superfície Nível 3 (--bcb-hc-bg-level-3: #333333)
Bordas de separação possuem contraste nítido (--bcb-hc-border: #FFFFFF).
