Catálogo de Protótipos & Telas

Ambiente de Prototipagem Projetos Modulares Diagramados por IA • Banco Central do Brasil

Vitrine oficial de telas de alta fidelidade projetadas autonomamente pelo motor de IA do BCB a partir de demandas reais. Cada interface foca rigorosamente no fragmento de conteúdo central (<main id="conteudo-principal">... </main>), desacoplado de cascas externas, com grid modular de 12 colunas, acessibilidade técnica (e-MAG 3.1 / WCAG 2.2 AA) e suporte integral aos 3 temas oficiais.

code_blocks

1. Protótipo Autônomo

Todo protótipo possui um envelope técnico mínimo para visualização direta, delimitando o conteúdo estritamente dentro de <main id="conteudo-principal" class="bcb-main-content">:

  • Envelope Mínimo: Contém <!DOCTYPE html>, <head> com links institucionais e bcb-ui.js.
  • Sem casca do portal: Header, Footer, Barra Brasil e Breadcrumbs são terminantemente proibidos no arquivo.
  • Pronto para CMS: O miolo central pode ser extraído diretamente para publicação no portal institucional.
devices

2. Visualizador Técnico (_harness.html)

O visualizador técnico atua como sandbox de homologação limpa via <iframe> nativo, eliminando simulações de cascas fixas para focar exclusivamente no conteúdo:

  • Pré-visualização Pura e Autônoma: Renderização direta do envelope semântico sem injeção de cascas simuladas (sem cabeçalho ou rodapé fictícios).
  • Alternador Rápido de Viewports: Alternância imediata entre Desktop (100% fluido), Tablet (768px centrado) e Mobile (375px centrado com moldura).
  • Abertura Direta e Isolada: Botão dedicado para abrir o protótipo autônomo em nova aba sem dependências de visualizadores externos.
alt_route

3. Fluxo com o Agente

Ciclo ágil de 5 etapas para conceber e homologar interfaces no Banco Central:

  1. Intake da Demanda: Crie o briefing via npm run demanda:criar.
  2. Diagramação IA: O agente gera o protótipo autônomo em prototipos/<slug>.html.
  3. Homologação no Visualizador: Inspecione no visualizador de resoluções (_harness.html).
  4. Auditoria Técnica: Valide via npm run test:prototypes.
  5. Exportação CMS: Exporte o miolo limpo via npm run prototipo:exportar.

code Fluxo de Prototipagem e Homologação de Demandas

  1. Crie a demanda: Execute npm run demanda:criar -- --slug meu-servico --titulo "Título" para gerar o scaffold em .docs-ia/exemplos-demandas/.
  2. Instrua o agente: Forneça o markdown preenchido ao agente indicando a intenção e o padrão de UX desejado (ex.: "Gere o protótipo para esta resolução adotando o layout 70/30 com downloads").
  3. Diagramação do miolo semântico: A IA projeta a interface em prototipos/meu-servico.html no container <main id="conteudo-principal"> com H1 único, grid modular de 12 colunas e botão voltar ao topo (isento de header, footer e breadcrumbs).
  4. Homologue no visualizador técnico: Abra prototipos/_harness.html?src=meu-servico.html para inspecionar a interface autônoma nos 3 viewports (Desktop 100%, Tablet 768px e Mobile 375px) e testar a responsividade de forma limpa.
  5. Valide a qualidade: Execute npm run test:prototypes para certificar conformidade WCAG 2.1 AA, linter estrito de miolo e ausência de scripts inline.
