Guia de Automação com Inteligência Artificial

Engenharia de Prompt & IA Diretrizes Oficiais para LLMs • Banco Central do Brasil • v2.0.0

Como webdesigners, comunicadores e desenvolvedores do Banco Central do Brasil podem utilizar Grandes Modelos de Linguagem (LLMs) e o agente integrado para prototipar telas completas e homologadas em questão de minutos.

smart_toy

O Propósito deste Guia

O ecossistema do BCB Design System foi desenhado com arquitetura semântica estrita para permitir que modelos como Google Gemini, Claude, ChatGPT e agentes Antigravity gerem código 100% pronto para produção, livre de alucinações e em total conformidade com o e-MAG 3.1 e WCAG 2.2 AA / AAA.

Basta fornecer o conteúdo em texto bruto ou dados da planilha ao modelo e combinar com um dos prompts estruturados abaixo.

verified_user 1. Regras Mandatórias de Geração de Código

Qualquer inteligência artificial ou desenvolvedor deve obedecer rigorosamente às 5 regras fundamentais de composição de interfaces do Banco Central:

check_circle O QUE FAZER (Mandatório)
  • Conteúdo Puro no <main>: Iniciar imediatamente a área de conteúdo com <main id="conteudo-principal" class="bcb-container container py-4 mb-5">.
  • H1 Único Rigoroso: Conter rigorosamente 1 tag <h1> por página com a classe .bcb-page-title. Subseções devem usar hierarquia estrita <h2> e <h3>.
  • Tokens Oficiais do Manual: Utilizar exclusivamente variáveis de design tokens (var(--bcb-brand-*), var(--bcb-color-*), var(--bcb-feedback-*)).
  • Resiliência de Dados: Sempre incluir Skeleton Loading (.bcb-skeleton, .table-skeleton) para carregamento e Empty State (.bcb-empty-state) para consultas sem retorno.
  • Clonagem de Templates: Iniciar sempre a criação a partir do template mais próximo da pasta templates/.
cancel O QUE NÃO FAZER (Proibido)
  • Proibição de Casca do Portal: NUNCA gerar <header>, <footer>, #barra-brasil ou .bcb-govbr-bar. O Design System foca 100% no miolo.
  • Proibição Definitiva de Breadcrumbs: NUNCA gerar <nav aria-label="breadcrumb"> ou .breadcrumb-bcb. A trilha de navegação é provida pela casca do CMS.
  • Cores Hexadecimais Arbitrárias: NUNCA inventar hexadecimais aleatórios no CSS inline. O contraste deve respeitar a identidade oficial do BCB.
  • Links Genéricos Proibidos: NUNCA criar links com texto "clique aqui", "saiba mais" ou "leia mais" (violação do critério WCAG 2.4.4).
  • Modo Escuro Fixo: NUNCA aplicar a classe .dark-mode fixa no <body> ou <main>. O tema é gerenciado globalmente via data-theme.

terminal 3. Como Rodar Localmente com Agentes Autônomos

Se você estiver utilizando o Google Antigravity IDE ou executando agentes na linha de comando, o projeto conta com uma skill nativa configurada em .agent/skills/gerador-ui-bcb/.

Fluxo de Execução com a Skill da IA

  1. Abra o workspace gov-ui-bacen no Antigravity.
  2. Abra o chat com o agente e peça a criação da tela fornecendo o briefing (a skill gerador-ui-bcb será ativada automaticamente).
  3. O agente analisará a necessidade, clonará o template mais próximo da pasta templates/ e aplicará as diretrizes semânticas.
  4. Valide a nova página executando a suíte completa de testes automatizados no terminal:
npm test

O comando valida integridade de tokens CSS, contraste WCAG 2.2, presença de H1 único e ausência de cascas externas e breadcrumbs.
