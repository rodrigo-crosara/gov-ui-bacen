code Fluxo de Prototipagem com o Motor Heurístico de IA

  1. Selecione o caso de referência: Identifique na galeria acima qual caso diagramado possui os componentes ideais para o seu conteúdo (tabelas, passos, alertas ou guias).
  2. Instrua o agente: Cole o texto bruto no chat e indique o caso de referência (ex: "Gere uma página para este comunicado baseada em templates/template-noticia.html").
  3. Preserve a integridade semântica: A IA gerará o miolo no elemento <main id="conteudo-principal"> com exatamente um <h1> e sem resíduos de casca.
  4. Valide com npm test: Execute o pipeline de auditoria técnica para garantir contraste WCAG 2.2 e e-MAG 3.1.
