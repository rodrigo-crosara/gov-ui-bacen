Convenções de Versionamento

O Design System do Banco Central do Brasil adota o modelo SemVer (Semantic Versioning) no formato MAJOR.MINOR.PATCH:

MAJOR (Quebra de Compatibilidade)

Incrementado quando são realizadas mudanças incompatíveis na API de tokens, classes CSS descontinuadas ou reestruturações profundas de componentes.

MINOR (Novas Funcionalidades)

Incrementado quando novos componentes, tokens adicionais ou melhorias retrocompatíveis são adicionados à biblioteca.

PATCH (Correções de Bugs)

Incrementado para correções de bugs, ajustes de contraste visual, refinamentos de documentação ou correções de CSS menores.
