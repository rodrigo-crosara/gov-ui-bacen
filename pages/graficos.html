Gráficos e Tabelas Analíticas

Especificação técnica e componentes interativos alinhados ao Manual Corporativo de Padrão Visual para Tabelas e Gráficos do Banco Central do Brasil. Padronização obrigatória para publicações analíticas (REF, Relatório de Inflação, Atas do Copom, SGS) e sistemas de informação digital do BCB.

tokens.color.chart

check_circle Regras Normativas do Manual Corporativo:

  • Ordem Sequencial Fixa: A 1ª série de qualquer gráfico é invariavelmente #2E4C59. A 2ª série é sempre #F2B557, e assim sucessivamente. É expressamente proibido sortear cores ou inverter a ordem.
  • Linhas de Grade Neutras (Gridlines): Cor #606060 com 50% de opacidade (rgba(96, 96, 96, 0.5)), garantindo discrição sem poluir a leitura dos dados.
  • Eixos e Rótulos: Cor estrutural padrão #606060. Tipografia obrigatória Arial, sans-serif.

3. Modelos Oficiais de Tabelas Analíticas

_tables.css

O BCB adota duas modalidades de tabelas analíticas com regras estritas de tipografia (Arial), alinhamento (primeira coluna à esquerda, números à direita), altura de linha de 12.75pt a 14pt e realce de números negativos em vermelho de alto contraste (#B30000).

4. Diretrizes e Boas Práticas Corporativas

Conformidade Obrigatória

tune Regras para Tabelas Analíticas

  • Alinhamento Rígido: Rótulos textuais e cabeçalhos de descrição sempre à esquerda. Valores numéricos, taxas e datas sempre à direita.
  • Separadores Verticais: Apenas na primeira coluna ou separação estrutural de blocos temporais (classe .bcb-col-separator de 0.5pt).
  • Linhas de Grade Internas: Não utilizar grades em xadrez completas no Padrão Estrito. O espaço em branco é o delimitador natural.
  • Números Negativos: Obrigatoriamente com a classe .num-negative, garantindo contraste WCAG AAA e visualização imediata de déficit/queda.

auto_graph Regras para Gráficos Highcharts

  • Sequência Cromática: Nunca altere a ordem das séries. Séries monofásicas utilizam exclusivamente a 1ª cor #2E4C59.
  • Legendas e Rótulos: Inseridos sempre com tipografia Arial, 8pt a 9pt, na cor neutra #606060.
  • Sem Gradientes Artificiais: O Manual do BC prioriza a precisão estatística; evite sombras 3D ou gradientes que distorçam os valores.
  • Acessibilidade & e-MAG: Forneça sempre atributos role="region" e aria-label nos contêineres de gráficos, acompanhados de tabela de dados subjacente quando cabível.

5. Snippets e Código de Integração

HTML & JavaScript

5.1 Integração de Gráfico com Highcharts e Tema BCB

<!-- 1. Carregue o Highcharts oficial e o tema corporativo do BCB -->
<script src="https://code.highcharts.com/highcharts.js"></script>
<script src="../assets/js/highcharts-theme-bcb.js"></script>

<!-- 2. Contêiner acessível para o gráfico -->
<div id="meuGrafico" class="bcb-chart-container" role="region" aria-label="Evolução de crédito"></div>

<script>
// O tema corporativo BCB já aplica as 12 cores, Arial e localização pt-BR automaticamente!
Highcharts.chart('meuGrafico', {
  chart: { type: 'line' },
  title: { text: 'Taxa de Inadimplência do Sistema Financeiro' },
  subtitle: { text: 'Operações com atraso superior a 90 dias — Pessoas Físicas e Jurídicas' },
  xAxis: { categories: ['Jan', 'Fev', 'Mar', 'Abr', 'Mai', 'Jun'] },
  yAxis: { title: { text: 'Em %' } },
  series: [
    { name: 'Pessoas Físicas', data: [3.4, 3.5, 3.4, 3.6, 3.5, 3.3] }, // Usa Série 01 (#2E4C59)
    { name: 'Pessoas Jurídicas', data: [2.1, 2.0, 2.2, 2.1, 2.0, 1.9] } // Usa Série 02 (#F2B557)
  ]
});
</script>
